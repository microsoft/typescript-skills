# Security

Do not report security vulnerabilities through public GitHub issues.

Report vulnerabilities to the [Microsoft Security Response Center](https://msrc.microsoft.com/create-report).
Include the affected files and revision, reproduction steps, expected impact,
and a proof of concept where possible. See Microsoft's
[security reporting guidance](https://aka.ms/security.md) for details.

Microsoft follows [Coordinated Vulnerability Disclosure](https://aka.ms/security.md/cvd).
